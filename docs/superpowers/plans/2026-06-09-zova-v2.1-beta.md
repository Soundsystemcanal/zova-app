# Zova v2.1 Beta — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add 5 independent features to Zova Android: persona Gaïa pré-chargée, partage de persona par QR code, widget Android 2×1, chapitrage automatique des longues sessions, et tableau de bord insights par persona.

**Architecture:** Single-file Capacitor app (`buddy/www/index.html`, ~8500 lignes). Les features 3.1/3.4/3.5 modifient uniquement ce fichier. La feature 3.2 modifie aussi `AndroidManifest.xml` et `package.json`. La feature 3.3 est entièrement en Java natif (4 fichiers nouveaux + manifest). Les features sont totalement indépendantes — ordre d'implémentation libre.

**Tech Stack:** Single-file HTML/CSS/JS + Capacitor 8 + Android Java. Groq API (`llama-3.1-8b-instant`) pour LLM post-session. QR via `https://api.qrserver.com` (pas de librairie JS nécessaire). Plugins Capacitor: `window.Capacitor.Plugins.Filesystem`, `.Share`, `.App` (nouveau pour 3.2).

```javascript
    // Deep link import — zova://import?p=<base64>
    function handleDeepLink(url) {
        if (!url) return;
        try {
            const parsed = new URL(url);
            if (parsed.protocol === 'zova:' && parsed.pathname === '//import') {
                const p = parsed.searchParams.get('p');
                if (!p) return;
                const json = decodeURIComponent(escape(atob(p)));
                processPersonaJson(json);
            }
        } catch(e) {
            console.error('[Zova] Deep link parse error', e);
        }
    }

    // Écouter les deep links Capacitor (app déjà ouverte ou lancée via URL)
    if (IS_CAPACITOR && window.Capacitor.Plugins.App) {
        window.Capacitor.Plugins.App.addListener('appUrlOpen', (event) => {
            handleDeepLink(event.url);
        });
        // Vérifier si l'app a été lancée via un deep link (cold start)
        window.Capacitor.Plugins.App.getLaunchUrl().then(result => {
            if (result && result.url) handleDeepLink(result.url);
        }).catch(() => {});
```

### 3D — AppWidgetProvider Java

- [ ] **Step 4: Créer ZovaWidget.java**

Créer `buddy/android/app/src/main/java/com/buddy/voiceapp/ZovaWidget.java` :

```java
package com.buddy.voiceapp;

import android.app.PendingIntent;
import android.appwidget.AppWidgetManager;
import android.appwidget.AppWidgetProvider;
import android.content.Context;
import android.content.Intent;
import android.widget.RemoteViews;

/**
 * Widget Android 2×1 — raccourci Zova sur l'écran d'accueil.
 * Affiche icône mic + "Zova" + "Appuyer pour parler".
 * Tap → ouvre MainActivity (conversation directe).
 *
 * Pas de refresh dynamique (updatePeriodMillis=0) — statique.
 * Pour afficher le nom de la persona active, une future version
 * pourrait écrire en SharedPreferences depuis JS via un plugin Capacitor.
 */
public class ZovaWidget extends AppWidgetProvider {

    @Override
    public void onUpdate(Context context, AppWidgetManager appWidgetManager, int[] appWidgetIds) {
        for (int widgetId : appWidgetIds) {
            updateWidget(context, appWidgetManager, widgetId);
        }
    }

    private static void updateWidget(Context context, AppWidgetManager manager, int widgetId) {
        RemoteViews views = new RemoteViews(context.getPackageName(), R.layout.widget_zova);

        // PendingIntent : ouvre MainActivity au tap
        Intent intent = new Intent(context, MainActivity.class);
        intent.setFlags(Intent.FLAG_ACTIVITY_NEW_TASK | Intent.FLAG_ACTIVITY_CLEAR_TOP);
        PendingIntent pendingIntent = PendingIntent.getActivity(
            context, widgetId, intent,
            PendingIntent.FLAG_UPDATE_CURRENT | PendingIntent.FLAG_IMMUTABLE
        );
        views.setOnClickPendingIntent(android.R.id.content, pendingIntent);

        // Fallback : click sur tout le widget (certains launchers utilisent l'ID root)
        // On pose le PendingIntent sur la LinearLayout via son ID implicite —
        // pour les widgets, le click handler sur la vue root est le plus fiable.
        // Avec widget_zova.xml la racine est la LinearLayout, pas android.R.id.content.
        // Solution : wrapper dans un FrameLayout ou utiliser setOnClickPendingIntent sur R.id.widget_mic_icon
        views.setOnClickPendingIntent(R.id.widget_mic_icon, pendingIntent);

        manager.updateAppWidget(widgetId, views);
    }
}
```

```javascript
    async function generateChapters(persona, transcriptText) {
        if (!transcriptText.trim()) return;
        const lineCount = transcriptText.split('\n').filter(l => l.trim()).length;
        if (lineCount < 40) return; // Session trop courte — pas de chapitrage

        try {
            const groqKey = await SecureStore.get('groq_api_key');
            if (!groqKey) return;

            const systemPrompt = `Tu es un assistant qui analyse des transcriptions de conversations vocales.
Identifie 3 à 5 chapitres thématiques dans la conversation ci-dessous.
Pour chaque chapitre, donne :
- title : titre court du chapitre (5-7 mots max)
- summary : résumé en 1-2 phrases de ce qui a été discuté
- exchanges : approximation du moment ("échanges 1-8", "échanges 9-20", etc.)

Réponds UNIQUEMENT avec un JSON valide, sans texte avant ou après.
Format : [{"title":"...","summary":"...","exchanges":"..."}]`;

            const result = await chatCompletion(
                groqKey,
                [
                    { role: 'system', content: systemPrompt },
                    { role: 'user', content: transcriptText.slice(0, 6000) }
                ],
                'llama-3.1-8b-instant',
                0.3
            );

            if (!result) return;

            // Parser le JSON (parfois avec backticks markdown)
            const cleaned = result.replace(/```json\n?|\n?```/g, '').trim();
            const chapters = JSON.parse(cleaned);
            if (!Array.isArray(chapters) || chapters.length === 0) return;

            const personaId = persona ? persona.id : getActiveId();
            localStorage.setItem('buddy_chapters_' + personaId, JSON.stringify(chapters));
            localStorage.setItem('buddy_chapters_ts_' + personaId, new Date().toISOString());

            console.log('[Zova] Chapitres générés:', chapters.length, 'pour', personaId);

            // Afficher le banner si on est sur l'écran home
            showChaptersBanner(personaId, persona ? persona.name : '');
        } catch(e) {
            console.error('[Zova] generateChapters error:', e);
        }
    }
```

```javascript
            const m = Math.floor(sec / 60), s = sec % 60;
```

Avant d'utiliser `getPersonaProfile(id)` dans la Task 5 (Insights), vérifier dans index.html qu'elle prend bien un `id` en paramètre (ajouté en Feature 3 — Task 5 de la session précédente). Si la signature a changé, adapter l'appel.

### Widget + SharedPreferences (amélioration future)

Le widget v2.1 affiche toujours "Zova" statiquement. Pour afficher la persona active, il faudrait :
1. Un plugin Capacitor custom qui écrit en `SharedPreferences` depuis JS
2. `ZovaWidget.java` qui lit ce `SharedPreferences`
3. Trigger un refresh via `AppWidgetManager.updateAppWidget()`

Non implémenté en v2.1 par souci de complexité — noter pour v2.2.

### QR code offline

`api.qrserver.com` nécessite internet. Si l'utilisateur n'a pas de réseau, le `<img>` affiche "QR indisponible" (géré par `onerror`). Pour une future version hors-ligne, intégrer une librairie QR inline (ex: `qrcode-generator` par kazuhikoarase, ~8KB, MIT).

### Chapitrage — sécurité des clés

`generateChapters()` utilise `SecureStore.get('groq_api_key')` — si la clé Groq n'est pas configurée, la fonction retourne silencieusement. Aucun message d'erreur visible pour l'utilisateur (intentionnel — feature bonus, pas critique).

### Compatibilité données existantes

Aucune migration destructive. Toutes les clés `buddy_chapters_*` et `buddy_chapters_ts_*` sont nouvelles. L'ajout de Gaïa est non-destructif (append only). Pas de changement au format `buddy_stats`.
