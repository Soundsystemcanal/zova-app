# Fase C — Wizard / Personas (Bloque 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Añadir la **evolución rápida de un persona existente** (2.7), disciplinar el **tamaño del prompt** generado (2.3, ≤900 chars) y mostrar **chips de sugerencia dinámicos** en el paso 1 del wizard basados en el perfil del usuario (2.2).

**Architecture:** Todo en `buddy/www/index.html`. (2.7) Un botón "✨ Évoluer" en el modal de edición de persona, junto a "Créer"/"Optimiser", que pide al usuario una directriz libre vía `customPrompt()`, fusiona el prompt actual + la directriz con un meta-prompt de mutación vía `chatCompletion()` (≤900 chars), y escribe el resultado en `#pPrompt` para que el usuario lo revise y guarde (mismo patrón que Créer/Optimiser — la persistencia ocurre en el botón Guardar existente, vía `savePersonas()`). (2.3) Se añade la restricción de 900 caracteres al meta-prompt del wizard y un recorte de seguridad. (2.2) Tras los chips estáticos del paso 1, se inyectan hasta 3 chips extra desde `getUserProfile().topics`.

**Tech Stack:** HTML single-file + Capacitor, `chatCompletion()` (router unificado de Bloque 4.3), `customPrompt()` (v3.1), `getPersonas()`/`savePersonas()`. Sin build de JS — sync con `npx cap sync android`.

**Verificación (sin test runner):** preview `zova-preview` (`buddy/www`). Las funciones de la app viven en un closure → NO accesibles por eval global; se verifica por (a) ausencia de errores en consola tras recargar, (b) la app renderiza (`.welcome-card` presentes), (c) presencia/estado de elementos DOM nuevos (`#evolvePromptBtn`, chips). Dispositivo (Xiaomi 14T) solo para E2E final.

Insertar tras el cierre `});` del handler `optimizePromptBtn` ([index.html:5993](../../../buddy/www/index.html)):

```javascript
    // Évoluer le persona : fusionne le prompt actuel avec une directive libre de l'utilisateur (≤900 chars)
    document.getElementById('evolvePromptBtn').addEventListener('click', async () => {
        const name = document.getElementById('pName').value.trim() || 'Mon assistant';
        const current = document.getElementById('pPrompt').value.trim();
        const hint = document.getElementById('promptHint');
        if (!current) { customAlert(t('persona_evolve_need'), { icon: '&#10024;' }); return; }
        if (!await hasAnyApiKey()) { customAlert(t('apikey_required_msg') || 'Configurez d\'abord une clé API.', { title: t('apikey_required_title') || 'Clé API', icon: '&#128273;' }); return; }

        const directive = await customPrompt(t('persona_evolve_msg'), {
            title: t('persona_evolve'), icon: '&#10024;', type: 'text',
            placeholder: t('persona_evolve_ph'), confirmLabel: t('persona_evolve')
        });
        if (!directive || !directive.trim()) return;

        const langName = LANG === 'es' ? 'español' : LANG === 'en' ? 'english' : 'français';
        const btn = document.getElementById('evolvePromptBtn');
        btn.disabled = true; hint.textContent = t('persona_evolve_working');
        try {
            const systemMsg = `Tu es un optimiseur de system prompts pour un assistant VOCAL temps réel.
Fusionne le « Prompt original » avec les « Directives d'évolution » fournies par l'utilisateur.
Conserve l'identité du persona et les règles de conversation orale. Applique les directives sans tout réécrire inutilement.
Retourne UNIQUEMENT le prompt fusionné, opérationnel et concis, en ${langName}, limité STRICTEMENT à 900 caractères maximum. Aucun texte avant ou après.`;
            const userMsg = `Prompt original (persona « ${name} ») :\n${current}\n\nDirectives d'évolution :\n${directive.trim()}`;
            let evolved = await chatCompletion({ systemPrompt: systemMsg, userPrompt: userMsg, temperature: 0.6, maxTokens: 600 });
            if (evolved) {
                evolved = evolved.trim();
                if (evolved.length > 900) evolved = evolved.slice(0, 900);
                document.getElementById('pPrompt').value = evolved;
                hint.textContent = t('persona_evolve_done');
            } else {
                hint.textContent = t('persona_evolve_empty');
            }
        } catch (err) {
            hint.textContent = `Erreur : ${err.message}`;
        } finally {
            btn.disabled = false;
        }
    });
```

por:
```javascript
        const sugg = WIZ_TOPIC_SUGGESTIONS[LANG] || WIZ_TOPIC_SUGGESTIONS.fr;
        // Chips dinámicos: hasta 3 intereses del perfil del usuario que no dupliquen los estáticos
        const prof = getUserProfile();
        const dyn = [];
        if (prof && Array.isArray(prof.topics)) {
            const lowerStatic = sugg.map(s => s.toLowerCase());
            for (const tpc of prof.topics) {
                const tt = (tpc || '').toString().trim();
                if (tt && tt.length <= 40 && !lowerStatic.includes(tt.toLowerCase()) && !dyn.some(d => d.toLowerCase() === tt.toLowerCase())) dyn.push(tt);
                if (dyn.length >= 3) break;
            }
        }
        const staticHtml = sugg.map(s => `<span class="wiz-chip" data-topic="${s}">${s}</span>`).join('');
        const dynHtml = dyn.map(s => `<span class="wiz-chip wiz-chip-dyn" data-topic="${esc(s)}">✨ ${esc(s)}</span>`).join('');
        document.getElementById('wizTopicChips').innerHTML = staticHtml + dynHtml;
        document.querySelectorAll('#wizTopicChips .wiz-chip').forEach(c =>
            c.addEventListener('click', () => {
                const ta = document.getElementById('wizTopic');
                ta.value = ta.value ? ta.value + ', ' + c.dataset.topic : c.dataset.topic;
                wizardData.topic = ta.value;
                updateWizNav();
            }));
```
(El `data-topic` del chip dinámico usa `esc(s)`; el texto visible lleva `✨` para distinguirlo. La clase `wiz-chip-dyn` permite estilo futuro pero hereda de `.wiz-chip` por ahora.)
