# Selector único de proveedor para tareas de texto (DeepSeek/Qwen seleccionables) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hacer que DeepSeek (R1 y chat) y Qwen sean **seleccionables y usables** para todas las tareas de texto (memoria, wizard, perfil, consolidación, chapitrage, limpieza de transcript) mediante un único selector en Config → Modèles, en lugar de quedar como un fallback dormido detrás de Groq/OpenAI/Gemini.

**Architecture:** Hoy las 8 funciones de texto hacen "Groq primero → si falla, `chatCompletion()` (OpenAI→Gemini→DeepSeek→Qwen)". Groq vive **fuera** de `chatCompletion()`. Este plan pliega Groq **dentro** de `chatCompletion()` como un proveedor más, y hace que un único selector (`buddy_modelMemory`, reetiquetado a "tâches texte") decida **qué proveedor se intenta primero**; el resto queda como cadena de respaldo. Cada uno de los 8 sitios se simplifica a una sola llamada a `chatCompletion()` (se borra el bloque Groq inline). El selector es la única fuente de verdad → se elimina el `preferReasoning` hardcodeado (el usuario puede elegir "DeepSeek-R1" para todo).

**Tech Stack:** HTML single-file + Capacitor, `fetch()` nativo, `SecureStore` (Keystore). Sin build de JS — `index.html` se sincroniza con `npx cap sync android`.

**Verificación (este proyecto NO tiene test runner):** preview navegador (`zova-preview` → `buddy/www`). El parseo se prueba evaluando `typeof fn === 'function'` o `chatCompletion.length`. El ruteo lógico se prueba poniendo claves de prueba y comprobando a qué endpoint sale el error de red (sin necesidad de claves reales). Dispositivo (Xiaomi 14T) solo para E2E final.

```javascript
    // Devuelve el proveedor/modelo de texto elegido en el selector #modelMemorySelect.
    // Valores Groq = id de modelo crudo; 'ds-reasoner'/'ds-chat'/'qwen' = compatibles OpenAI.
    function getTextProvider() {
        const v = (typeof getModelMemory === 'function')
            ? getModelMemory()
            : (localStorage.getItem('buddy_modelMemory') || 'llama3-8b-8192');
        if (v === 'ds-reasoner') return { type: 'deepseek', model: COMPAT_PROVIDERS.deepseek.reasoner };
        if (v === 'ds-chat')     return { type: 'deepseek', model: COMPAT_PROVIDERS.deepseek.chat };
        if (v === 'qwen')        return { type: 'qwen',     model: COMPAT_PROVIDERS.qwen.chat };
        return { type: 'groq', model: v }; // cualquier id de modelo Groq
    }

    // Lookup de clave por tipo de proveedor de texto.
    async function textProviderKey(type) {
        if (type === 'groq')     return await getGroqApiKey();
        if (type === 'openai')   return await getApiKey();
        if (type === 'gemini')   return await getGeminiApiKey();
        if (type === 'deepseek') return await getDeepseekApiKey();
        if (type === 'qwen')     return await getQwenApiKey();
        return null;
    }

    // Dispatch de UNA llamada a un proveedor concreto. Devuelve texto o lanza Error.
    async function callTextProvider(type, model, key, { systemPrompt, userPrompt, temperature, maxTokens }) {
        if (type === 'groq') {
            const resp = await fetch('https://api.groq.com/openai/v1/chat/completions', {
                method: 'POST',
                headers: { 'Authorization': `Bearer ${key}`, 'Content-Type': 'application/json' },
                body: JSON.stringify({
                    model,
                    messages: [
                        { role: 'system', content: systemPrompt },
                        { role: 'user', content: userPrompt }
                    ],
                    max_tokens: maxTokens,
                    temperature
                })
            });
            if (!resp.ok) {
                const err = await resp.json().catch(() => ({}));
                throw new Error(err.error?.message || `HTTP ${resp.status}`);
            }
            return ((await resp.json()).choices?.[0]?.message?.content || '').trim();
        }
        if (type === 'gemini') {
            const resp = await fetch(`https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent?key=${encodeURIComponent(key)}`, {
                method: 'POST',
                headers: { 'Content-Type': 'application/json' },
                body: JSON.stringify({
                    system_instruction: { parts: [{ text: systemPrompt }] },
                    contents: [{ role: 'user', parts: [{ text: userPrompt }] }],
                    generation_config: { temperature, max_output_tokens: maxTokens }
                })
            });
            if (!resp.ok) {
                const err = await resp.json().catch(() => ({}));
                throw new Error(err.error?.message || `HTTP ${resp.status}`);
            }
            return ((await resp.json()).candidates?.[0]?.content?.parts?.[0]?.text || '').trim();
        }
        // openai / deepseek / qwen — todos formato OpenAI
        const base = type === 'openai' ? 'https://api.openai.com/v1'
                   : type === 'deepseek' ? COMPAT_PROVIDERS.deepseek.base
                   : COMPAT_PROVIDERS.qwen.base;
        return await postOpenAIFormat({ base, key, model, systemPrompt, userPrompt, temperature, maxTokens });
    }
```

- [ ] **Step 2: Reescribir el cuerpo de `chatCompletion()`**

Reemplazar TODA la función `chatCompletion` actual (desde `async function chatCompletion(` hasta su `}` de cierre, ~[4432-4495](../../../buddy/www/index.html)) por:

```javascript
    // Punto de entrada ÚNICO para tareas de texto/batch (memoria, wizard, perfil...).
    // El proveedor elegido en el selector se intenta PRIMERO; el resto es cadena de respaldo.
    // Incluye Groq (ya no se llama a Groq por separado fuera de aquí).
    async function chatCompletion({ systemPrompt, userPrompt, temperature = 0.7, maxTokens = 2000 }) {
        const sel = getTextProvider();
        const cands = [];
        const push = (type, model) => {
            if (!cands.some(c => c.type === type && c.model === model)) cands.push({ type, model });
        };
        // 1) Lo que el usuario eligió, primero
        push(sel.type, sel.model);
        // 2) Cadena de respaldo (orden coste/calidad razonable)
        push('groq', 'llama3-8b-8192');
        push('openai', 'gpt-4o-mini');
        push('gemini', 'gemini-2.0-flash');
        push('deepseek', COMPAT_PROVIDERS.deepseek.chat);
        push('qwen', COMPAT_PROVIDERS.qwen.chat);

        const args = { systemPrompt, userPrompt, temperature, maxTokens };
        let lastErr = null;
        for (const c of cands) {
            const key = await textProviderKey(c.type);
            if (!key) continue;
            try {
                const out = await callTextProvider(c.type, c.model, key, args);
                if (out) return out;
            } catch (e) {
                lastErr = e;
                console.warn('[chatCompletion]', c.type, '→', e.message);
            }
        }
        throw lastErr || new Error('Aucune clé API configurée.');
    }
```
