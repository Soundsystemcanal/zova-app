# Bloque 5.3 — Borrado granular por ítem (derecho al olvido) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Permitir borrar **elementos individuales** (un recuerdo, un seguimiento, un objetivo, un dato del perfil) en vez de solo poder borrar la sección entera. Convierte las vistas "Voir…" de solo-lectura en gestores con una **✕ por ítem**.

**Architecture:** Todo en `buddy/www/index.html`. Se añade UN gestor de lista interactivo genérico `openItemManager({title, icon, emptyMsg, build, afterChange, footerHtml, onFooter})` que renderiza un `.dialog-overlay` con una fila por ítem (texto + botón ✕). `build()` devuelve `[{ text, remove }]` donde cada `remove()` muta su `localStorage`; tras borrar se re-renderiza llamando `build()` de nuevo y se refresca el contador. Cada una de las 5 vistas (`viewMemoryBtn`, `viewFollowupsBtn`, `viewGoalsBtn`, `viewProfileBtn`, `viewGlobalProfileBtn`) pasa a usar el gestor. Borrado inmediato al pulsar ✕ (sin confirm por ítem; el re-render da feedback). Los botones "Effacer" de sección y `wipeAllAiData` se conservan.

**Tech Stack:** HTML single-file + Capacitor. Getters/setters existentes: `getPersonaMemories`/`PERSONA_MEMORY_PREFIX`, `getMemories`/`MEMORY_KEY`, `getFollowUps`/`saveFollowUps`, `getGoals`/`saveGoals`, `getPersonaProfile`/`setPersonaProfile`, `getUserProfile`/`setUserProfile`. Helpers `esc()`, `customAlert()`. Sin build de JS — sync con `npx cap sync android`.

**Verificación (sin test runner):** preview `zova-preview`. Funciones en closure → no accesibles por eval global; pero el gestor se puede abrir vía UI (botones de Config) o sembrando `localStorage` y disparando el handler con `.click()`. Verificar: render de filas, que ✕ borra el ítem del `localStorage` y re-renderiza, contador actualizado. Dispositivo solo para E2E final.

```javascript
    // Gestor de lista interactivo genérico (Bloque 5.3 — borrado por ítem).
    // build() => [{ text, remove }]. footerHtml/onFooter opcionales (ej. exportar).
    function openItemManager({ title, icon = '🗂️', emptyMsg, build, afterChange, footerHtml = '', onFooter }) {
        const overlay = document.createElement('div');
        overlay.className = 'dialog-overlay';
        const close = () => overlay.remove();
        const render = () => {
            const items = build();
            const listHtml = items.length
                ? `<div class="item-manager-list">` + items.map((it, i) =>
                    `<div class="item-manager-row"><span>${esc(it.text)}</span><button class="item-manager-del" data-i="${i}" aria-label="✕">✕</button></div>`
                  ).join('') + `</div>`
                : `<div class="dialog-message" style="opacity:0.7">${esc(emptyMsg || '')}</div>`;
            overlay.innerHTML = `<div class="dialog-box">
                <div class="dialog-icon">${icon}</div>
                <div class="dialog-title">${esc(title)}</div>
                <div class="dialog-message" style="opacity:0.7;font-size:0.78rem">${t('manage_hint')}</div>
                ${listHtml}
                <div class="dialog-buttons" style="margin-top:12px;display:flex;gap:8px;justify-content:flex-end">
                    ${footerHtml}
                    <button class="dialog-btn" id="_imClose">${t('manage_close')}</button>
                </div>
            </div>`;
            overlay.querySelectorAll('.item-manager-del').forEach(btn =>
                btn.addEventListener('click', () => {
                    const idx = parseInt(btn.dataset.i, 10);
                    items[idx].remove();
                    if (afterChange) { try { afterChange(); } catch (e) {} }
                    render();
                }));
            overlay.querySelector('#_imClose').addEventListener('click', close);
            if (onFooter) {
                const fb = overlay.querySelector('#_imFooter');
                if (fb) fb.addEventListener('click', () => onFooter(build()));
            }
        };
        overlay.addEventListener('click', (e) => { if (e.target === overlay) close(); });
        render();
        document.body.appendChild(overlay);
    }
```

```javascript
    document.getElementById('viewMemoryBtn').addEventListener('click', () => {
        const activeId = getActiveId();
        openItemManager({
            title: t('config_section_memory'), icon: '🧠',
            emptyMsg: t('memory_none'),
            footerHtml: `<button class="dialog-btn" id="_imFooter">${t('manage_export')}</button>`,
            build: () => {
                const pmem = getPersonaMemories(activeId);
                const usePersona = pmem.length > 0;
                const arr = usePersona ? pmem : getMemories().filter(m => m.personaId === activeId || m.personaId === '');
                return arr.map(m => ({
                    text: `${m.date} — ${m.personaName || ''}: ${m.summary}`,
                    remove: () => {
                        if (usePersona) {
                            const a = getPersonaMemories(activeId);
                            const idx = a.findIndex(x => x.date === m.date && x.summary === m.summary);
                            if (idx > -1) { a.splice(idx, 1); localStorage.setItem(PERSONA_MEMORY_PREFIX + activeId, JSON.stringify(a)); }
                        } else {
                            const g = getMemories();
                            const idx = g.findIndex(x => x.date === m.date && x.summary === m.summary);
                            if (idx > -1) { g.splice(idx, 1); localStorage.setItem(MEMORY_KEY, JSON.stringify(g)); }
                        }
                    }
                }));
            },
            afterChange: () => updateMemoryCount(),
            onFooter: (items) => {
                if (!items.length) return;
                showExportModal(items.map((it, i) => `**${i+1}.** ${it.text}`).join('\n\n'), 'zova-memoires.txt');
            }
        });
    });
```
