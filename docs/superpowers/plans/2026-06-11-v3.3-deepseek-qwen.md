# Plan v3.3 — Arranque: Bloque 4 (Proveedores DeepSeek + Qwen)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Añadir DeepSeek y Qwen (Alibaba DashScope) como proveedores compatibles-OpenAI para las tareas de chat/batch de la app (wizard, memoria, resúmenes), reutilizando `chatCompletion()` sin librerías nuevas.

**Architecture:** DeepSeek y DashScope exponen una API 100 % compatible con el formato `POST /chat/completions` de OpenAI. Por eso NO tocamos la conversación de voz en tiempo real (OpenAI Realtime / Ultravox / Groq siguen igual): solo extendemos la función batch `chatCompletion()` ([buddy/www/index.html:4325](../../../buddy/www/index.html)) con una cadena de fallback OpenAI → Gemini → DeepSeek → Qwen, y añadimos las claves al modal `#apiKeyModal` con el mismo blindaje Android Keystore (`SecureStore`).

**Tech Stack:** HTML single-file + Capacitor, `capacitor-secure-storage-plugin` (vía wrapper `SecureStore`), `fetch()` nativo. Sin build de JS (el `index.html` se sincroniza con `npx cap sync android`).

**Alcance de este documento:** Bloque 4 completo, en tareas bite-sized. Los Bloques 1, 2, 3 y 5 quedan listados en la sección **Roadmap v3.3** al final, para expandirse en sus propios planes cuando se llegue a ellos (cada uno es un subsistema independiente).

- [ ] **Step 2: Añadir el helper genérico (DRY)**

OpenAI, DeepSeek y Qwen comparten exactamente la misma forma de body/respuesta. Extraerla a un helper, justo después de la constante:

```javascript
    // POST genérico formato OpenAI. Devuelve el texto de la respuesta o lanza Error.
    async function postOpenAIFormat({ base, key, model, systemPrompt, userPrompt, temperature, maxTokens }) {
        const resp = await fetch(`${base}/chat/completions`, {
            method: 'POST',
            headers: { 'Authorization': `Bearer ${key}`, 'Content-Type': 'application/json' },
            body: JSON.stringify({
                model,
                messages: [
                    { role: 'system', content: systemPrompt },
                    { role: 'user', content: userPrompt }
                ],
                temperature,
                max_tokens: maxTokens
            })
        });
        if (!resp.ok) {
            const err = await resp.json().catch(() => ({}));
            throw new Error(err.error?.message || `HTTP ${resp.status}`);
        }
        const data = await resp.json();
        return data.choices?.[0]?.message?.content?.trim() || '';
    }
```

## Task 3: Extender `chatCompletion()` con fallback DeepSeek → Qwen y opción de razonamiento

**Files:**
- Modify: `buddy/www/index.html:4325-4370` (cuerpo de `chatCompletion`)

- [ ] **Step 1: Reescribir la firma y el cuerpo**

La firma actual es `chatCompletion({ systemPrompt, userPrompt, temperature = 0.7, maxTokens = 2000 })`. Añadir `preferReasoning = false` (para que las tareas post-session puedan pedir DeepSeek-R1 explícitamente, Bloque 4.3). Reemplazar el cuerpo completo de la función ([index.html:4325-4370](../../../buddy/www/index.html)) por:

```javascript
    async function chatCompletion({ systemPrompt, userPrompt, temperature = 0.7, maxTokens = 2000, preferReasoning = false }) {
        // 0) Si se pide razonamiento profundo y hay clave DeepSeek, usar R1 primero
        if (preferReasoning) {
            const dsKey = await getDeepseekApiKey();
            if (dsKey) {
                return await postOpenAIFormat({
                    base: COMPAT_PROVIDERS.deepseek.base, key: dsKey,
                    model: COMPAT_PROVIDERS.deepseek.reasoner,
                    systemPrompt, userPrompt, temperature, maxTokens
                });
            }
        }

        // 1) OpenAI (gpt-4o-mini)
        const openaiKey = await getApiKey();
        if (openaiKey) {
            return await postOpenAIFormat({
                base: 'https://api.openai.com/v1', key: openaiKey, model: 'gpt-4o-mini',
                systemPrompt, userPrompt, temperature, maxTokens
            });
        }

        // 2) Gemini (formato propio, no OpenAI)
        const geminiKey = await getGeminiApiKey();
        if (geminiKey) {
            const resp = await fetch(`https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent?key=${encodeURIComponent(geminiKey)}`, {
                method: 'POST',
                headers: { 'Content-Type': 'application/json' },
                body: JSON.stringify({
                    system_instruction: { parts: [{ text: systemPrompt }] },
                    contents: [{ role: 'user', parts: [{ text: userPrompt }] }],
                    generation_config: { temperature, max_output_tokens: maxTokens }
                })
            });
            if (!resp.ok) {
                const err = await resp.json().catch(() => ({}));
                throw new Error(err.error?.message || `HTTP ${resp.status}`);
            }
            const data = await resp.json();
            return data.candidates?.[0]?.content?.parts?.[0]?.text?.trim() || '';
        }

        // 3) DeepSeek-chat (compatible OpenAI)
        const dsKey = await getDeepseekApiKey();
        if (dsKey) {
            return await postOpenAIFormat({
                base: COMPAT_PROVIDERS.deepseek.base, key: dsKey, model: COMPAT_PROVIDERS.deepseek.chat,
                systemPrompt, userPrompt, temperature, maxTokens
            });
        }

        // 4) Qwen (compatible OpenAI vía DashScope)
        const qwenKey = await getQwenApiKey();
        if (qwenKey) {
            return await postOpenAIFormat({
                base: COMPAT_PROVIDERS.qwen.base, key: qwenKey, model: COMPAT_PROVIDERS.qwen.chat,
                systemPrompt, userPrompt, temperature, maxTokens
            });
        }

        throw new Error('Aucune clé API configurée.');
    }
```
