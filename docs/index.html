Ce que Zova sait faire

🧠

Mémoire intelligente v3

Zova sélectionne les souvenirs les plus pertinents pour chaque conversation — par score de pertinence ET récence. Chaque persona a sa propre mémoire, indépendante des autres.

📌

Suivis d'engagements v3

Après chaque session, Zova détecte automatiquement tes engagements ("je vais faire X cette semaine") et les garde en mémoire pour les relancer naturellement à la prochaine conversation.

🎯

Objectifs long terme v3

Mentionne un objectif et Zova le retient. Session après session, ta progression est suivie et injectée dans le contexte. Consulte tes objectifs actifs dans Config.

💬

"Souviens-toi que…" v3

Dis simplement "souviens-toi que je préfère les réponses courtes" et Zova mémorise instantanément le fait — toast de confirmation, sauvegardé dans ton profil.

🔄

Reconnexion transparente

Quand la connexion coupe en pleine conversation, Zova reprend exactement là où elle s'était arrêtée — sans se réintroduire, sans oublier le contexte des échanges précédents.

📑

Chapitrage automatique

Les sessions longues (plus de 20 min) sont analysées après Stop : l'IA découpe la conversation en chapitres thématiques avec titres et résumés. Consultables via le bouton 📑.

📊

Profil adaptatif par persona

Chaque persona construit son propre profil de toi, adapté à son domaine. Ton coach fitness connaît tes objectifs physiques. Ton assistant code connaît ton stack.

📝

Export transcription + chapitres

Exporte ta conversation avec les chapitres en table des matières. Option "Nettoyer" : l'IA corrige les erreurs de reconnaissance vocale avant de partager.

🌍

App 100% trilingue v4

Interface, personas, wizard et prompts générés entièrement en espagnol, anglais ou français selon ta langue. Change à tout moment — tout suit.

🔒

Confidentialité granulaire v4

Efface tes souvenirs un par un depuis Config → Mémoire (bouton ✕). Ou supprime toutes les données IA d'un coup via Config → Confidentialité — personas et clés API préservés.

🚀

Démarrage simplifié v4.1

Une seule clé API suffit pour commencer — et Groq est gratuit. L'écran de config te le rappelle clairement et vérifie ta clé à l'enregistrement.

🛡️

Code PIN renforcé v4.1

Ton code PIN n'est plus jamais stocké en clair : seule son empreinte chiffrée (SHA-256) est gardée. Le verrou anti-essais est protégé dans le coffre sécurisé d'Android.

🎭

Avatar Zova animé v5

Une sphère Dark Cosmos s'anime en temps réel selon l'état de la conversation (écoute, réflexion, parole). Touche l'écran pendant qu'elle parle pour l'interrompre instantanément — avec double retour haptique.

🎙️

ElevenLabs TTS haute qualité v5

Avec le pipeline Groq, remplace la voix Android par des voix de qualité studio via ElevenLabs. La voix est choisie automatiquement d'après le profil vocal de ta persona. Sans clé, la voix Android prend le relai.

📋

Historial de sessions v5

Un onglet Historique dans les Statistiques liste toutes tes sessions en ordre antichronologique, groupées par jour, avec persona, durée et coût de chaque échange.

✨

Onboarding & mode immersif v5

Premier lancement sans clé API : un écran de bienvenue avec portrait Zova guide vers la config. En conversation : la navigation disparaît pour une expérience plein écran. Elle revient à l'arrêt.

Installer ou mettre à jour

1

Télécharger

Clique le bouton ou scanne le QR. Le dernier APK Zova se télécharge sur ton Android.

2

Autoriser

Paramètres → Apps → ton navigateur → "Installer des applis inconnues" → Autoriser. Puis ouvre le fichier APK.

3

Configurer

Ouvre Zova → Config → Clé API → colle ta clé Groq (gratuite). C'est prêt !

↻

Mise à jour

Déjà une version de Zova ? Installe le nouvel APK par-dessus : tes données, mémoires et clés API sont conservées (même app ID + signature). Ne désinstalle pas l'ancienne version.
