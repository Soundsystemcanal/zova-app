Pourquoi Zova ?

🔒

Souverain

Tes clés API sont chiffrées dans l'Android Keystore matériel. Zova ne voit jamais tes données — il n'existe aucun serveur Zova.

🎭

Personnalisable

Crée des assistants sur mesure : nom, personnalité, voix, prompt libre. Aucune limite, aucun filtre imposé par un tiers.

💸

Transparent

Paye exactement ce que tu utilises, directement au provider. Pas d'abonnement caché. Dès ~$0.001/min — ou gratuit pour commencer.

Installer en 3 minutes

1

Télécharger

Clique le bouton ou scanne le QR. Le fichier Zova-v1.1.apk (3,8 Mo) se télécharge sur ton Android.

2

Autoriser

Paramètres → Apps → ton navigateur → "Installer des applis inconnues" → Autoriser. Puis ouvre le fichier APK.

3

Configurer

Ouvre Zova → Config → Clé API → colle ta clé Groq (gratuite). C'est prêt !

Nouveautés v2-beta

📁

Export / Import fiable

Partage le backup via Drive, WhatsApp ou email — ou enregistre-le directement dans l'app. Réimport en un tap, sans chercher dans les dossiers Android.

🧠

Mémoire évolutive

Deux couches de mémoire : résumés de sessions + profil utilisateur cumulatif. L'app apprend à te connaître au fil du temps et injecte ce contexte dans chaque conversation.

🔑

Backup complet

Le fichier de sauvegarde inclut désormais personas, mémoires, profil, et optionnellement les clés API — pour une restauration totale en cas de réinstallation.

👤

Zova Profile Builder

Le persona Zova pose des questions progressives pour mieux te connaître. Chaque session enrichit le profil : préférences, style, objectifs, sujets récurrents.

Changelog v2-beta

Basé sur v1.1 · Branche v2-beta · 2026-06-09

1. Export / Import fiable (Android 11+)

  • NEWEnregistrer dans Zova — écrit le fichier dans le dossier privé de l'app via Filesystem.writeFile(EXTERNAL)
  • NEWPartager — share sheet Android natif (Drive, WhatsApp, email…)
  • NEWSauvegardes Zova à l'import — l'app liste ses propres fichiers directement, sans passer par le sélecteur Android (contourne scoped storage)
  • NEWClés API optionnelles dans le backup — demandées à l'export, restaurées séparément à l'import
  • FIXExport tronqué à 20 000 caractères — clipboard remplacé par Filesystem + Share
  • FIXFichier introuvable à l'import — contournement du scoped storage Android 11+

2. Mémoire évolutive — 2 couches

  • EXISTANTMémoire épisodique (buddy_memories) — résumés de sessions, max 10, injectés dans le prompt
  • NEWProfil utilisateur cumulatif (buddy_userProfile) — JSON mis à jour par LLM après chaque session : nom, langues, style, sujets, faits, objectifs
  • NEWLe profil est injecté dans le système prompt de tous les personas
  • NEWUI Config : voir le profil formaté, effacer, compteur de faits/sujets
  • NEWProfil inclus dans le backup/restore

3. Persona Zova — Profile Builder

  • NEWNouveau rôle : apprendre à connaître l'utilisateur progressivement (remplace l'hôtesse d'onboarding)
  • NEWLit le profil existant et pose 1-2 questions ciblées sur ce qui manque
  • NEWProgression : identité → vie/travail → style → objectifs → intérêts → approfondissement
  • NEWMigration automatique depuis l'ancienne version au premier lancement

4. Corrections de bugs

  • FIXEmojis et HTML affichés en brut dans les alertes — customAlert() utilise désormais innerHTML
  • FIXFiltre import incorrect (zova_backup → zova-backup)

5. Nouvelles dépendances

  • @capacitor/filesystem@8.1.2 — lecture/écriture fichiers Android
  • @capacitor/share@8.0.1 — share sheet natif Android
