Pourquoi Zova ?

🔒

Souverain

Tes clés API sont chiffrées dans l'Android Keystore matériel. Zova ne voit jamais tes données — il n'existe aucun serveur Zova.

🎭

Personnalisable

Crée des assistants sur mesure : nom, personnalité, voix, prompt libre. Chaque persona apprend à te connaître et s'améliore avec le temps.

🧠

Il se souvient

Mémoire épisodique + profil adaptatif par persona. Chaque conversation enrichit la relation. Reprend naturellement là où vous vous êtes arrêtés.

💸

Transparent

Paye exactement ce que tu utilises, directement au provider. Pas d'abonnement caché. Dès ~$0.001/min — ou gratuit pour commencer.

Installer en 3 minutes

1

Télécharger

Clique le bouton ou scanne le QR. Le fichier Zova-v2.0.apk (~4 Mo) se télécharge sur ton Android.

2

Autoriser

Paramètres → Apps → ton navigateur → "Installer des applis inconnues" → Autoriser. Puis ouvre le fichier APK.

3

Configurer

Ouvre Zova → Config → Clé API → colle ta clé Groq (gratuite). C'est prêt !

Manuel d'utilisation

🎤 Démarrer une conversation

  • Appuie sur le bouton central pour parler
  • L'écran reste allumé pendant la conversation (WakeLock)
  • Si la connexion se coupe, Zova reconnecte automatiquement (3 tentatives)
  • Appuie à nouveau pour terminer la session

🎭 Personas

  • Appuie sur le nom de la persona dans l'écran d'accueil pour changer
  • Config → Personas → "+" pour créer un assistant sur mesure
  • Chaque persona a son propre prompt, voix, mémoire et profil
  • La persona Zova apprend à te connaître au fil des conversations

🧠 Mémoire et profil adaptatif

  • Après chaque session, Zova génère un résumé et met à jour le profil (en arrière-plan)
  • Chaque persona a sa propre mémoire et son propre profil de toi
  • Config → section "Profil [nom persona]" pour voir ou effacer le profil actif
  • Lien discret "Voir le profil général" pour accéder au profil global commun
  • Config → Mémoires pour consulter ou effacer les résumés de sessions

📝 Transcription et export

  • La conversation s'affiche en temps réel dans l'onglet Transcription
  • Après la session : bouton "Exporter" pour partager le texte brut
  • Option "Nettoyer" : l'IA corrige les erreurs STT et ajoute la ponctuation
  • Partage via n'importe quelle app : email, WhatsApp, Notes, Drive…

💾 Backup et restore

  • Config → Exporter : partage via Drive/WhatsApp ou sauvegarde locale dans Zova
  • Inclut personas, mémoires, profils — option clés API en bonus
  • Config → Importer → "Sauvegardes Zova" pour restaurer sans chercher le fichier
  • Compatible Android 11+ (contourne les restrictions scoped storage)

🔐 Sécurité et PIN

  • Clés API chiffrées dans l'Android Keystore matériel (jamais en clair)
  • Option PIN 4 chiffres pour verrouiller l'accès à l'app
  • Aucune donnée envoyée à des serveurs Zova — connexion directe au provider
  • Les clés ne quittent ton téléphone qu'à l'export si tu le demandes explicitement

⚙️ Providers et clés API

  • Groq (pour débuter) : console.groq.com — quota gratuit
  • OpenAI : platform.openai.com
  • Gemini : aistudio.google.com
  • Ultravox : app.ultravox.ai

❓ Dépannage rapide

  • Bouton "?" dans Config → FAQ complète FR/EN/ES intégrée dans l'app
  • Pas de micro : Paramètres → Apps → Zova → Permissions → Micro → Autoriser
  • Voix muette : normal sur Android WebView — le texte s'affiche quand même
  • Xiaomi : active "Débogage USB" + "Installer via USB" dans Options développeur
