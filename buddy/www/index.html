Configuration

Cette application nécessite au moins une clé API (OpenAI ou Gemini) pour fonctionner. Veuillez en configurer une pour commencer.
ℹ️ Minimum : une seule clé. Groq est gratuit et le plus simple pour démarrer. Les autres sont optionnelles.
Nécessaire pour les modèles OpenAI (gpt-realtime).

Comment obtenir une clé API OpenAI :

  1. Créez un compte sur platform.openai.com
  2. Rendez-vous dans API Keys
  3. Cliquez sur "Create new secret key"
  4. Copiez la clé générée et collez-la ci-dessus

Assurez-vous d'avoir activé la facturation et d'avoir du crédit disponible.

Nécessaire pour les modèles Gemini. Stockée localement.

Comment obtenir une clé API Gemini :

  1. Rendez-vous sur Google AI Studio
  2. Connectez-vous avec votre compte Google
  3. Cliquez sur "Create API Key"
  4. Copiez la clé générée et collez-la ci-dessus
Pour les conversations Ultravox (~$0.005/min). Clé gratuite disponible.

Comment obtenir une clé API Ultravox :

  1. Créez un compte sur app.ultravox.ai
  2. Rendez-vous dans Settings → API Keys
  3. Cliquez sur "Create API Key"
  4. Copiez la clé générée et collez-la ci-dessus

Ultravox propose un quota gratuit généreux pour débuter.

Pour le pipeline Groq STT→LLM→TTS (~$0.001/min). Le moins cher.

Comment obtenir une clé API Groq :

  1. Créez un compte sur console.groq.com
  2. Rendez-vous dans API Keys
  3. Cliquez sur "Create API Key"
  4. Copiez la clé générée et collez-la ci-dessus

Groq est gratuit avec un quota très généreux — idéal pour commencer.

Pour la synthèse vocale ElevenLabs (TTS haute qualité). Optionnelle.

Comment obtenir une clé API ElevenLabs :

  1. Créez un compte sur elevenlabs.io
  2. Allez dans votre profil → API Keys
  3. Cliquez sur "Create API Key"
  4. Copiez la clé et collez-la ci-dessus

ElevenLabs offre un quota gratuit mensuel pour commencer.

Accès à des centaines de modèles (Claude, GPT, Mistral…) avec une seule clé. Voix (pipeline) et tâches texte.

Comment obtenir une clé API OpenRouter :

  1. Créez un compte sur openrouter.ai
  2. Rendez-vous dans Settings → Keys
  3. Cliquez sur "Create Key"
  4. Copiez la clé (sk-or-…) et collez-la ci-dessus

Paiement à l'usage (prix du modèle +5%), sans abonnement.

Pour les tâches texte (mémoire, wizard, profil) à bas coût. Optionnelle.

Comment obtenir une clé API DeepSeek :

  1. Créez un compte sur platform.deepseek.com
  2. Allez dans API Keys et créez une clé
Pour les tâches texte multilingues à bas coût. Optionnelle.

Comment obtenir une clé API Qwen :

  1. Créez un compte sur Alibaba Cloud Model Studio
  2. Créez une clé API dans la console DashScope
